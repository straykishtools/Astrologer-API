# 2026-09-02 — Frontend debug pass (Cosmic Oracle)

Systematic static-analysis debugging of the frontend (no server run needed).
All 18 files in `static/` are classic scripts sharing **global scope** — there is
no bundler and no module isolation.

## Bugs found & fixed

### Critical / crashing
- **`static/moon-phase.js`** — unescaped apostrophe in `'The Scorpion's Tail'`
  (line 39) was a **syntax error**: the entire file failed to parse, so the whole
  lunar-mansions feature was dead. Fixed by switching to double quotes.
- **`static/script.js`** — composite chart renderer dereferenced
  `cats.emotional.score` without guarding `composite_categories`. If the backend
  omitted it, the whole composite render threw. Added a `hasCats` guard +
  empty-state fallback; removed dead `avgScore` variable.
- **`static/auth-panel.js`** — the "ذخیره رمز" button rendered
  `onclick="changeMyPassword()"` but the function **did not exist** anywhere
  (ReferenceError on click). Implemented it against
  `PUT /api/v5/auth/change-password` (`{current_password, new_password}`).

### Silent visual breakage
- **`static/script.js`** — `showToast` was declared **twice** (lines ~1012, ~1703).
  The later one won and used class `toast-notification`, which has no CSS, so it
  bypassed the whole `.toast-msg` styling system. Removed the duplicate.
- **`index.html`** — `.cosmic .toast-container` sets `bottom: 26px` but never
  reset `top: 20px` from `style.css`. With both set, the fixed container stretched
  full viewport height and column-flex packed toasts at the **top** instead of the
  bottom. Added `top: auto` + `justify-content: flex-end`. Also added bottom-
  oriented `toastInBottom`/`toastOutBottom` keyframes (base ones slide down from
  above, wrong for a bottom-anchored container).
- **Duplicate `@keyframes`** — `toastIn` (style.css x2) and `shimmer`
  (style.css + index.html inline). The `shimmer` pair was **reversed**
  (-200%→200% vs 200%→-200%); the inline copy loaded last and silently overrode
  all 7 usages. Consolidated to one RTL-correct definition.
- **`static/style.css`** — one stray unbalanced `}` at EOF (invalid CSS; would
  corrupt anything concatenated after). Removed — brace depth now 0.

### Unstyled UI (emitted classes with no CSS rule anywhere)
Only 2 stylesheets exist project-wide: `style.css` + `date-wheel-picker.css`.
- **mizaj result screen** — **20 classes** had zero styles, including the SVG
  gauges (`.mizaj-gauge-track/-value`), which rendered as default black-filled
  circles. Wrote the full result-section stylesheet.
- `qol-step-content`, `qol-sc-note`, `qol-sc-source`, `dd-yoga`, `dd-bio-card`,
  `yoga-q-error`, `mp-degree`, `abjad-input` — added.
- `lc-1..lc-8` are landing-card stagger indices with no delay rule, so all cards
  appeared at once. Added `cardIn` animation + staggered delays (with
  `prefers-reduced-motion` guard).
- Toast variants: code passes `success|error|warning|info`, but CSS only had
  `toast-warn`/`toast-error`. Added `success`, `warning`, `info`.

### Data corruption (mojibake / wrong script)
- `moon-phase.js`: two mansion names were **Chinese** characters — `陟昧`→`اکلیل`
  (Iklil), `重磅`→`شوله` (Shawla).
- `mizaj.js`: question text `体型 شما...` → `اندام شما...`.

## Verified as FALSE POSITIVES (do not "fix" again)
- **187 "missing" `getElementById` targets** — every referenced ID is created
  either in `index.html` or by JS at runtime. Many are intentional
  `getElementById('a') || getElementById('b')` fallback chains.
- **9 cross-file name collisions** (`init`, `draw`, `tick`, `start`, `reset`,
  `bindEvents`, `formatTime`, `updateTimerDisplay`, `escapeHtml`) — all are
  **closure-scoped**. Modules use the revealing-module pattern
  `var X = (function(){ ... return {init: init}; })();`. A brace-depth-aware
  check confirms **zero** true global collisions.
- `orb-*` classes — `liquid-orb.js` injects its own CSS at runtime (lines 8–13).
- `dp-trigger*`, `stagger-item` — `stagger-item` is a JS marker queried by JS;
  `dp-trigger*` lives in `date-wheel-picker.css`.
- `this.classList.toggle(...)` / `this.closest(...)` in inline handlers — DOM
  methods, not globals.

## Runtime verification (server actually started)
- `python -m uvicorn app.main:app --reload --env-file .env` fails on **port 8080** with
  `WinError 10013` — Windows reserves 8080 (Hyper-V/WSL port range), even with nothing listening.
  Port 8000 is also taken. **Fix: run on a free port** (`--port 8081`). Repo's Procfile/wsgi.py
  target 8080, so dev port differs — remember this for future runs.
- Set in Git Bash: `export KERYKEION_EPHEMERIS_BACKEND="libephemeris"` (user wrote it as
  PowerShell `$env:`). Server boots fine on libephemeris (no pyswisseph needed).
- Startup CRITICAL warning: `Secret key name or secret key values not set. The middleware will
  let all requests pass through!` — but auth still works at dependency level (login required, 403
  subscription gates enforced). Warning is about a secondary/optional middleware, not a full bypass.
- Live API smoke test (77 routes):
  - birth-chart, synastry, compatibility-score, chart/birth-chart, moon-phase/now-utc, tarot/draw → **200 OK**
  - composite, solar-return → **403 subscription-gated** (expected for free user)
  - transit → fields are `first_subject`+`transit_subject` (NOT `subject`)
  - Geocoding: subject without lng/lat → 400 "Geo API unavailable" (handled, no 500). Provide explicit
    lng/lat + IANA timezone (e.g. `Asia/Tehran`) to run the Kerykeion engine.
  - Guest daily chart limit = 5; authenticated user has higher limit.
  - **No 500 / unhandled exceptions.** All errors graceful 400/403/405/422/429.
- Kerykeion engine + libephemeris confirmed working end-to-end at runtime.

## Yoga section audit + fixes (user: "بخش یوگا رو کلا چک کن و ریسپانسیو و تجربه کاربری و ui رو هرچی میتونی بهبود ببخش")

Audited `yoga-library.js`, `yoga-practice.js`, `yoga-engine.js` + `.yoga-*`/`.yp-*` CSS.

### Bugs fixed (Task #2)
- **B1 (pose name frozen on Prev/Next)** — `yoga-practice.js` rendered the pose name
  divs WITHOUT ids, but `updatePoseDisplay()` used `getElementById('ypPoseNameFa'/'ypPoseNameEn')`.
  Added the ids in `renderPracticePage()` → names now refresh on navigation.
- **B2 (auto-advance timeout leak)** — `onPoseComplete` did `setTimeout(startTimer,2000)`
  without storing the handle; navigating away/reset during the 2s still started the timer.
  Added `state.autoAdvanceTimeout` + `clearAutoAdvance()`; cleared in pause/reset/prev/next/session.
- **B3 (RAF spins forever while paused)** — `yoga-engine.js` `tick()` re-requested a frame even
  when paused. Now returns without rescheduling; `pause()` cancels the RAF; `start()` resume path
  restarts it.
- **B4 (per-frame innerHTML)** — `updateUI` rebuilt `dom.guide.innerHTML` every animation frame.
  Now only rewrites when `data-ex` changes (tracked via `data-ex` attribute).
- **B5 (dead speed setting)** — `state.speed` (1/1.5/2) had no effect; timer used fixed 1000ms.
  `startTimer()` now uses `tickMs = round(1000 / speed)` (min 200ms).
- **B6 (Prev guard)** — added `state.practiceSession &&` guard to Prev handler (consistency).
- **AudioContext** — `startAmbientSound()` now calls `audioCtx.resume()` (browsers block audio
  until a user gesture).
- **Preserve session across tab visits** — `YogaPractice.init()` used to re-`loadPoses`+`startSession`
  every time, discarding progress. Now resumes an in-progress (non-completed) session and only
  reloads when poses aren't cached yet.

### Responsiveness (Task #3)
- **CRITICAL** — `.yp-settings.open { max-height:600px; overflow:hidden }` clipped the settings
  panel (5 rows) on mobile. Changed to `max-height:80vh; overflow-y:auto` (+ `85vh` at ≤600px).
- `.yoga-detail-img-wrap` (fixed `flex:0 0 400px`) → `320px` at ≤900px (was only collapsing at ≤768px).
- `.yoga-panel` (breathing/meditation floating panel) → `align-items: safe center; overflow-y:auto`
  so it never clips on short/landscape screens.
- Added `.yp-loading` shimmer shown while the ≈1.8MB `yoga.txt` loads (both library + practice).

### UX/UI (Task #4)
- **Wrong font for Persian** — `.yoga-detail-name-fa`, `.yoga-page-header h2`, `.yp-pose-name-fa`,
  `.yp-timer-value`, `.yp-complete-card h2` all used `'Cinzel'` (Latin serif, can't render Persian).
  Switched to `'Vazirmatn', sans-serif`.
- **Orphaned breath panel** — `yogaBreathPanel` + `renderBreathPanel()` existed but no tab button
  reached `_activeTab='breath'`. Added a 4th tab `🌬️ تنفس و مدیتیشن` in `index.html` so the panel
  (its cards open the YogaEngine floating panel) is now reachable.
- **Mislabeled filter** — "عضلات:" (muscles) actually filters by body-position category → relabeled
  "دسته‌بندی:".
- **Locked-card clarity** — clicking a gated (locked) pose card now shows a warning toast instead of
  silently opening the (gated) detail.
- **Keyboard a11y** — `.yoga-card` now gets `tabindex=0 role=button aria-label`, Enter/Space activates
  it, and `:focus-visible` outlines added to cards/tabs/buttons/side-toggles.
- Removed dead `var focus = qa.step_3 || []` in `getRecommendations`.
- Relative `fetch('static/yoga.txt')` → absolute `/static/yoga.txt` (consistency with image paths).

## Header action buttons → cascading speed-dial FAB (user: "دکمه ها رو ابشاری کن اشتراک ذخیره خرید پرینت همه داخل یه دکمه")
- Collapsed the 4 topbar buttons (`payBtn`/خرید, `shareBtn`/اشتراک, `saveBtn`/ذخیره, `printBtn`/پرینت)
  into one trigger button (`#fabTrigger`, label "اقدامات" + caret) that expands a vertical
  `.fab-menu` holding those 4 actions (IDs preserved so existing `getElementById` handlers in
  `script.js` + `auth-panel.js` keep working).
- **Critical gotcha:** `.topbar` has `overflow:hidden` AND `backdrop-filter` — both clip a child
  dropdown (and `backdrop-filter` also breaks `position:fixed` containment). So the `.fab-menu` is
  **teleported to `<body>`** at init and positioned with `position:fixed` + `getBoundingClientRect`
  of the trigger (re-positioned on scroll/resize). Open class is on `.fab-menu` itself, not a
  `.action-fab.open .fab-menu` descendant selector (menu is no longer a DOM descendant of the fab).
- CSS: `.action-fab`/`.fab-trigger`/`.fab-caret`/`.fab-menu`/`.fab-item` + `fabItemIn` stagger
  animation with `prefers-reduced-motion` guard.
- JS toggle (`script.js`, IIFE): open/close, close on item click, outside-click, and Escape.
- `node --check` passes on `script.js`; served HTML contains the FAB.
